VoiceRemedy 0.8.1 is a patch release of the offline singing coach for Windows, Android, and Fire tablets.

## Changes
Added an About section with version info.

## Downloads
- Windows: VoiceRemedy-0.8.1-Windows-Setup.exe
- Android / Fire: VoiceRemedy-0.8.1-Android-Fire.apk
- Installation instructions: INSTALL.md
- File verification: SHA256SUMS-0.8.1.txt

The Windows installer is unsigned. The Android / Fire APK is signed with a dedicated release key for personal sideloading. It is not a Play Store or Amazon Appstore build.

The key that signed 0.7.0 is no longer available, so 0.7.1 uses a new signing key. Android and Fire refuse to install 0.7.1 over 0.7.0. Uninstall 0.7.0 once, then install 0.7.1. Uninstalling clears the on-device practice history. 0.8.1 keeps the 0.7.1 key, so it installs over 0.8.0 and keeps that history.

The app measures pitch, not overall vocal technique or vocal health.
