VoiceRemedy 0.8.0 is a feature release of the offline singing coach for Windows, Android, and Fire tablets.

## Languages
Now available in Spanish, French, German, Portuguese (Brazil), Italian, Russian, Polish, Japanese, Korean and Chinese (Simplified). Apps use your system language by default; change it any time in Settings → Language.

The control is the Language field inside Adjust my session. Spoken coach clips stay in English. The words on screen follow the language you choose.

## Downloads
- Windows: VoiceRemedy-0.8.0-Windows-Setup.exe
- Android / Fire: VoiceRemedy-0.8.0-Android-Fire.apk
- Installation instructions: INSTALL.md
- File verification: SHA256SUMS-0.8.0.txt

The Windows installer is unsigned. The Android / Fire APK is signed with a dedicated release key for personal sideloading. It is not a Play Store or Amazon Appstore build.

The key that signed 0.7.0 is no longer available, so 0.7.1 uses a new signing key. Android and Fire refuse to install 0.7.1 over 0.7.0. Uninstall 0.7.0 once, then install 0.7.1. Uninstalling clears the on-device practice history. 0.8.0 keeps the 0.7.1 key, so it installs over 0.7.1 and keeps that history.

The app measures pitch, not overall vocal technique or vocal health.
