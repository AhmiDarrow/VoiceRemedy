# Install VoiceRemedy

Installers are collected in `releases/`. Lessons, coaching audio, and pitch analysis work offline after installation.

## Windows PC

Open `VoiceRemedy-0.7.0-Windows-Setup.exe` and follow the installer. It installs for your current Windows account and creates a Start menu entry. Windows may identify this local build as unsigned. Microsoft WebView2 is required; the installer can download it if it is missing.

Open VoiceRemedy, press **Start my lesson**, and follow the spoken coach. Allow microphone access when Windows or the app asks. If access is denied, check Windows Settings → Privacy & security → Microphone, including access for desktop apps.

## Android phone or tablet

Copy `VoiceRemedy-0.7.0-Android-Fire.apk` to the device and open it in its file manager. Android may ask you to permit installation from that file manager. Install, open VoiceRemedy, and allow microphone access when you begin a practice. No Google account or Play services are needed.

## Fire HD 10, 2021 or newer

1. Use the adult/parent profile to install the app.
2. Connect the tablet to your PC by USB, select file transfer if prompted, and copy `VoiceRemedy-0.7.0-Android-Fire.apk` into the tablet's Downloads folder.
3. Open the APK from the tablet's file manager. If Fire OS blocks installation, use its **Install unknown apps** setting to allow that file manager, then open the APK again. Menu names vary by Fire OS version.
4. Open VoiceRemedy and allow its microphone when starting an exercise. The first lesson is **Find your starting note**.
5. You can revoke the file manager's unknown-app installation permission afterward; VoiceRemedy will continue to work.

The same APK supports Android and Fire. It does not require installing the Play Store or replacing the Fire operating system. Amazon lists the 2021 Fire HD 10 as Fire OS 7 / Android API 28; this app's minimum is API 24. Compatibility is designed for that range but needs confirmation on your physical tablet.

Amazon Kids profiles restrict access to sideloaded apps. Installing in the parent profile does not guarantee that the APK will appear in a child profile. If it cannot be shared through the tablet's normal parental controls, use the parent profile with your supervision. VoiceRemedy contains no ads, purchases, accounts, external links, or social features.

## A gentle first practice

Use a quiet room and tap **Start my lesson**. The female coach explains, plays a reference, says get ready, and gives a soft chime for your turn. Hum gently, then hear your feedback. Tap **What's next?** or **Help me with that** to continue. **Pause session** stops the coach and microphone at any time.

Choose **Teach me a song** for song instruction or **Find my comfortable note** to choose an easier starting point. **Adjust my session** contains shorter turns and other options. The speaker control enables a text-guided alternative.

If no clear voice is detected, the app asks you to try again instead of inventing a score. If anything feels uncomfortable, stop and rest.
## Build status

The APK is debug-signed for personal sideloading, and the Windows installer is unsigned. Neither is a Play Store/Amazon Appstore release. Keep the same Android signing key for future upgrades if you want to preserve on-device history. Uninstalling the app clears its local practice history.


## Teach your own song

Choose **Upload a song**, select an audio file, and choose a short section. Tap **Find the melody**, review or edit the estimated notes, then choose **Teach me this melody** and **Start my lesson**.

Your audio stays local. Solo singing works best; a full band recording can confuse the melody estimate. The coach teaches the reviewed notes, with simplified practice timing. Saved sections are available in **Adjust my session → Work on**.
